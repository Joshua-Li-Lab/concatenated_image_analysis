# Multi-Stain Concatenation - Fusion Benchmark

Slide-level cross-validation trainer for comparing different ways of
combining multiple histopathology stains (H&E + IHC) to classify tissue tiles
as **normal vs. adenocarcinoma**.

Stains used: `HE`, `TTF1`, `MNF116`, `p53`, `MIB1` (reference = `HE`).
